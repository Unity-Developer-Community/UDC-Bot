| **Image Spam Guard** | Stops the common scam wave of messages with exactly 4 images (text optional, forwards included). The first such message from a member is only remembered; another one in a different channel within the window deletes every remembered message, times the member out, and posts one report to the bot-announcement channel with the messages, channels, timeout result and one image from the last message (picked at random, shrunk to at most 720 px and saved as JPEG; only PNG, JPEG, GIF, WebP and BMP up to 40 megapixels) so moderators can check for false positives. It then posts a short pointer to the report in the AutoMod channel (mentions don't ping); without `Channels.AutoMod` the pointer is skipped with a startup warning. Bots, webhooks, admins, members with Manage Messages and the Moderator role are exempt. State is in memory only. Settings: `ImageSpamGuard` (`Enabled`, off by default; `ImageCount` 4; `WindowMinutes` 15; `TimeoutHours` 24) and `Channels.AutoMod`. Needs **Manage Messages** and **Moderate Members**, the bot's top role must be above the member's, and **Send Messages** in the AutoMod channel | — | `ImageSpamGuardService` | Feature |

## Slash Commands vs Text Commands

The bot supports both paradigms:

- **Text Commands** — Prefix-based (default `!`), implemented in `*Module.cs` classes
- **Slash Commands** — Discord's native slash commands, implemented in `*SlashModule.cs` and `*InteractiveModule.cs` classes

For a full command reference, see the `!Help` command or `/help` slash command in Discord.
